# Weather App

Aplicativo simples de clima feito em Python.

## Funcionalidades

- Busca clima por nome da cidade
- Mostra temperatura atual
- Mostra sensação térmica
- Mostra umidade
- Mostra condição do clima
- Exibe cidade, estado/região e país

## Tecnologias usadas

- Python
- Requests
- Open-Meteo API

## Como executar

```bash
pip install -r requirements.txt
python weather.py
